# nextgen-legal

Published legal documents for NextGen Academy's mobile apps. Served by GitHub
Pages at **https://legal.nextgentrainingacademy.com/** so each store listing has
a stable, public, login-free URL on the company domain.

Deliberately *not* hosted on the Vercel project that serves the main site: that
account is on the Hobby plan, which is not licensed for commercial use, and a
suspended host means a dead privacy-policy URL and a pulled Play listing.

One folder per app. Nothing here is generated at request time and nothing is
fetched from the network — each folder is a self-contained static page.

| App | Document | URL |
|---|---|---|
| Karina Fake Video Call | Privacy policy | https://legal.nextgentrainingacademy.com/karina-fake-video-call/ |

Source of truth for the Karina policy is `docs/PRIVACY_POLICY.md` in that app's
repo; `docs/privacy/` there is the deployable copy this folder mirrors. Edit it
there, then copy the folder across — do not diverge the two.
